# صرح أروقة الخلود — معمارية صيغة MTX المضغوطة (MTX Binary Codec Engine v2.0)

> **موقع إلكتروني أدبي وتحريري رفيع المستوى لقراءة ونشر الروايات والمصنفات التراثية والفلسفية، يعتمد تقنية ترميز وضغط ثنائية مبتكرة ومخصصة للنصوص العربية المشكولة.**

---

## ١. ما هي صيغة MTX (Matrix / Modular Text Xenon)؟

صيغة **`.mtx`** هي حاوية ثنائية مخصصة (Custom Binary Container) صُممت خصيصاً لحل معضلات تخزين ونقل النصوص العربية والروايات الأدبية الطويلة عبر شبكة الويب؛ حيث تعاني النصوص العربية المشكولة (Diacritized Arabic) في صيغة UTF-8 التقليدية من تضخم هائل في الحجم (لأن كل حركة وتشكيل يشغل بايتين إضافيين في UTF-8)، مما يبطئ عمليات التحميل ويزيد استهلاك قواعد البيانات ونطاق التردد.

توفر صيغة **MTX v2.0** ضغطاً غير فقود بنسبة **٧٠٪ إلى ٨٢٪** مقارنة بـ UTF-8 الخام، مع زمن فك تشفير خيالي لا يتجاوز **٠٫٣ إلى ٢ ميلي ثانية** في المتصفح، مع الحفاظ الصارم بنسبة ١٠٠٪ على كل علامة ترقيم وحركة وتنوين دون أي ضياع.

---

## ٢. الهيكل الثنائي لملف `.mtx` (Binary Format Specification)

يتكون ملف `.mtx` الثنائي من ترويسة رئيسية ثابتة بحجم ٢٠ بايتاً تليها حمولة مشفرة ومضغوطة:

```
+-------------------------------------------------------------------------+
|                  MTX v2.0 Header (20 Bytes Fixed)                       |
+-------------------+-------------------+-------------------+-------------+
| Magic (4B): MTX2  | Version (1B): 0x02| Flags (1B): 0x07  | Salt (4B)   |
+-------------------+-------------------+-------------------+-------------+
| Checksum (4B)     | Raw UTF-8 Size (4B)| Dict Entries (2B)|             |
| (Adler-32)        | (Uint32)          | (Uint16)          |             |
+-------------------+-------------------+-------------------+-------------+
|                     Encrypted & Compressed Payload                      |
|  - JSON Metadata (Title, Author, Chapter, Word Count, Tags)             |
|  - Dynamic Merged Substrings (Chapter-specific BPE Table)               |
|  - Token Stream (1-byte per Token)                                      |
+-------------------------------------------------------------------------+
```

### حقول الترويسة (Header Layout):
1. **Magic Bytes (`0x00 - 0x03`)**: أربعة بايتات تعريفية `0x4D, 0x54, 0x58, 0x32` تمثل السلسلة النصية `"MTX2"`.
2. **Version (`0x04`)**: رقم إصدار المحرك (حالياً `0x02` للإصدار الثاني).
3. **Flags (`0x05`)**: بتات تفعيل الميزات (القاموس الثابت، دمج السوابق واللواحق، قاموس BPE الديناميكي، تشفير التدفق المتناظر).
4. **Salt / Keystream Seed (`0x06 - 0x09`)**: بذرة عشوائية من ٤ بايتات (Uint32) لتوليد مفتاح التعمية الانسيابي.
5. **Adler-32 Checksum (`0x0A - 0x0D`)**: قيمة فحص النزاهة للنص الأصلي لضمان الاسترجاع التام (Lossless Verification).
6. **Original Raw UTF-8 Size (`0x0E - 0x11`)**: الحجم الأصلي للنص بالبايت قبل الضغط.
7. **Dictionary Entries Count (`0x12 - 0x13`)**: عدد مفردات القاموس الديناميكي المستخرجة من الفصل.

## ٣. مراحل خط أنابيب الضغط (Multi-Tier Compression Pipeline)

يعمل محرك الضغط في `src/app/core/mtx-codec.ts` عبر أربع طبقات هندسية متتالية:

### الطبقة الأولى: القاموس الصرفي العربي المسبق (Precompiled Morphological Vocab)
بدلاً من حزم الحروف الفردية كبايتات متفرقة، يحتوي المحرك على جدول مسبق يضم:
- **الأبجدية العربية والحركات الكاملة**: الفتحة، الضمة، الكسرة، السكون، التنوين بأنواعه، والشدة (`0x064B` - `0x0652`).
- **جرافيمات التشكيل المركبة الأكثر تكراراً**: دمج الحرف مع حركته في رمز واحد مثل (`كَ`، `كِ`، `مَ`، `مُ`، `لَ`، `لِ`، `رَ`...).
- **السوابق الصرفية المدمجة**: (`وبالـ`، `كالـ`، `فالـ`، `للـ`، `والـ`، `بالـ`، `الـ`...).
- **اللواحق والضمائر المتصلة**: (`هما`، `هم`، `هن`، `كم`، `نا`، `ها`، `ين`، `ون`، `ات`...).
- **دمج علامات الترقيم والمسافات**: (`، `، `؛ `، `. `، `؟ `، `! `، `: `، `.\n`، `\n— `...).
- **المفردات السردية الشائعة في الأدب العربي**: (`قال`، `قالت`، `كان`، `كانت`، `في`، `على`، `من`، `إلى`، `عن`، `مع`...).

### الطبقة الثانية: خوارزمية BPE التكيفية لكل فصل (Chapter-Specific BPE)
يحلل المحرك النص المدخل لاكتشاف الكلمات والتراكيب الفريدة المتكررة بكثافة داخل الرواية المعينة (مثل أسماء الأبطال، الأماكن، والعبارات الملحمية)، ويقوم بدمجها ديناميكياً وتضمين قاموسها الخاص في ترويسة الحمولة.

### الطبقة الثالثة: ترميز تيار البايت الأحادي (1-Byte Token Stream)
يتم تعيين كل عنصر في القاموس إلى قيمة تتراوح بين `0` و `255` (بايت واحد فقط لكل مقطع، سابقة، أو كلمة كاملة)، مما يقلص حجم النص العربي المكتوب إلى أقل من ثلث حجمه الأصلي.

### الطبقة الرابعة: ضغط الإنتروبيا العالي وخوارزمية Deflate
تُمرر الحمولة الثنائية عبر خوارزمية `Deflate` بأعلى مستوى ضغط (`level: 9`) باستخدام مكتبة `fflate` فائقة الخفة والأداء، مما يعصر التكرارات الإحصائية النهائية.

### الطبقة الخامسة: التشفير المتناظر الانسيابي (Symmetric PRNG XOR Keystream)
لحماية الملكية الفكرية ومنع سرقة الروايات من ذاكرة التخزين المؤقت، يتم تشفير البايتات الناتجة باستخدام مولد أرقام شبه عشوائي (Pseudo-Random Keystream) يعتمد على البذرة (Salt) ومفتاح التشفير السري الخاص بالمنصة.

## ٤. فك التشفير والتشغيل اللحظي (Instant Client-side Decompression)

عندما يفتح القارئ أي رواية أو فصل:
1. يستقبل المتصفح مصفوفة بايتات `Uint8Array` (أو Base64 من التخزين السحابي).
2. يتحقق فوراً من توافق الـ Magic Bytes (`MTX2`).
3. يفك التشفير الانسيابي بواسطة الـ Salt المستخرج من الترويسة.
4. يفك الضغط باستخدام `inflateSync` في أقل من ميلي ثانية واحدة.
5. يعيد تركيب النص الأصلي فوراً حرفاً بحرف وحركة بحركة.
6. يحسب الـ Checksum عبر خوارزمية Adler-32 ويطابقها مع الترويسة للتأكد بنسبة ١٠٠٪ من سلامة النص التام.

## ٦. منظومة حماية المحتوى التحريري (Editorial Content Protection)

لحماية جهود المؤلفين والمحققين في صرح أروقة الخلود، يحتوي الموقع على نظام حماية مركزي في `src/app/core/content-protection.ts`:
- تعطيل تحديد النصوص بالكامل (`user-select: none !important`).
- منع أحداث النسخ والقص والسحب (`copy`, `cut`, `dragstart`).
- إغلاق القائمة المنبثقة للزر الأيمن (`contextmenu`).
- حظر اختصارات النسخ والحفظ (`Ctrl+C`, `Ctrl+X`, `Ctrl+U`, `Ctrl+S`, `Ctrl+P`).
- استثناء ذكي وآمن لحقول البحث والإدخال المصرح بها فقط.
